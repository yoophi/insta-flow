# Insta Flow

프로필에서 게시물을 열면 사진·영상을 원본 비율로 브라우저 표시 영역에 최대한 크게 표시하고 댓글 패널을 숨깁니다.

- 좌우 화살표 버튼 / ← →: 같은 게시물의 이전·다음 사진 또는 영상
- 첫 사진에서 ←: 이전 게시물의 마지막 사진으로 이동
- 마지막 사진에서 →: 다음 게시물의 첫 사진으로 이동
- 상하 화살표 버튼 / ↑ ↓: 이전·다음 게시물
- 최상단 반투명 **원래 화면 / 전체화면** 버튼: 기본 Instagram 레이아웃과 확대 화면 전환. 기본 화면에서는 확장 프로그램의 방향키 처리를 해제합니다.
- 도구 모음과 탐색 화살표는 2.5초간 조작이 없으면 숨겨집니다. 마우스 이동·클릭·키보드 입력 시 다시 표시합니다. 키보드 포커스가 있는 버튼은 표시를 유지합니다.
- **자동 시작 / 자동 정지**: 지정한 간격으로 이동하며 기본값은 3초입니다. 간격은 1~3600초로 변경할 수 있습니다.
- **정방향**: 다음 사진 → 마지막 사진이면 다음 게시물의 첫 사진.
- **랜덤**: 현재 게시물의 사진·영상을 마지막 장까지 순서대로 표시한 뒤, 프로필별로 저장한 게시물 ID 목록을 한 번 섞은 뒤 그 순서대로 첫 장부터 재생합니다. 현재 게시물은 제외하며 한 바퀴 안에서는 같은 게시물을 다시 선택하지 않습니다. 저장 후보가 없으면 정방향으로 이동합니다. 화면에 없는 게시물은 모달을 잠시 닫고 프로필 목록을 스크롤해 찾은 뒤 다시 엽니다. 이 과정에서 자동 재생 설정은 유지됩니다.
- 게시물 화면을 갱신하는 동안 영역이 잠깐 사라지면 최대 2초간 기다립니다. 복구되지 않거나 실제로 게시물 화면을 벗어나면 자동 이동을 중지하고 이유를 표시합니다.
- 원래 화면으로 복귀하면 자동 이동을 중지합니다. 다른 브라우저 탭을 보는 동안에는 자동 이동을 건너뜁니다.
- 자동 이동 중 사진은 지정한 간격으로 넘기고, 영상은 `영상만` 선택 여부와 관계없이 실제 재생이 끝난 뒤 넘깁니다. 영상을 일시정지하면 기다립니다. 영상의 반복 재생은 자동 이동 중 잠시 해제하고 자동 정지 시 복원합니다.
- **영상만**: 사진을 건너뛰고 영상이 있는 슬라이드 또는 게시물을 찾습니다. 자동 이동과 수동 탐색에 적용됩니다. 영상 탐색은 최대 2분이며, 목록 끝에서 영상을 찾지 못하면 중지합니다.
- 게시물 목록 양 끝에서는 Instagram이 제공하는 이동 범위를 따릅니다.

## 설치

1. Chrome에서 `chrome://extensions`를 엽니다.
2. 개발자 모드를 켜고 **압축해제된 확장 프로그램을 로드합니다**를 누릅니다.
3. 이 저장소를 내려받은 폴더를 선택합니다.
4. Instagram 탭을 새로고침합니다.

기존 버전을 사용 중이면 확장 프로그램 관리 화면에서 **새로고침**한 뒤, Instagram 탭도 새로고침하고 프로필에서 게시물을 다시 엽니다.

Instagram의 현재 게시물 모달 DOM에 맞춘 초기 버전입니다. Instagram의 클래스나 구조가 변경되면 선택자를 수정해야 합니다. 독립 게시물 페이지·릴스 전용 화면은 별도 지원 대상입니다.

## 검증

실제 Instagram 프로필 게시물 모달에서 이미지 확대, 댓글 숨김, 사진/게시물 경계 이동, 좌우/상하 방향키, 원래 화면 토글, 3초 자동 이동, 랜덤 게시물 이동, 사진 건너뛰기 후 영상 도착을 확인했습니다. Dbo1uthEq2P 게시물의 7번째 가로 사진과 8번째 세로 사진 전환 및 호버 시 비율 유지도 확인했습니다.

0.2.3에서는 캐러셀 영역에 페인트 경계를 설정해 옆 사진이 가장자리에 비치지 않도록 하고, 반응형 이미지 후보 교체 중 같은 사진의 비율을 유지하며 표시 크기를 디바이스 픽셀에 맞춥니다. 확대 화면의 페이지 스크롤바도 고정합니다.

0.2.4에서는 전체/영상만 자동 재생 모두 영상 종료를 기다립니다. 1초 사진 간격을 초과해도 영상이 유지되고, 일시정지 중 이동하지 않으며, 실제 `ended` 이벤트 후 다음 게시물 첫 장으로 이동하는 것을 확인했습니다. 게시물 이동 버튼이 없는 영상 뷰어에서는 프로필 목록의 다음 게시물을 사용합니다.

## 프로필 목록 저장 (0.4.0)

1. 프로필의 게시물 목록을 엽니다. 게시물 모달에서 바로 새로고침했다면 프로필 목록으로 돌아와 주세요.
2. **목록 수집**을 누르면 목록을 위에서부터 스크롤하며 게시물 주소를 누적합니다. 수집 도중 **수집 중지**를 눌러도 이미 수집한 주소는 유지됩니다. 수동 스크롤로 발견한 게시물도 자동으로 누적합니다.
3. 게시물을 열고 **랜덤 → 자동 시작**을 선택하면 저장 목록에서 이동 대상을 선택합니다.

- 프로필 및 목록 종류(게시물·릴스·태그됨)별로 분리해 `chrome.storage.local`에 저장합니다. 사진·영상 원본은 저장하지 않습니다. 새로고침하거나 Chrome을 다시 실행해도 목록을 다시 사용할 수 있습니다.
- 게시물 ID로 중복을 제거합니다. 랜덤 재생은 현재 게시물을 제외한 ID 목록을 섞고 차례로 순회합니다. 남은 목록을 모두 재생하면 현재 게시물을 제외하고 다시 섞습니다. 수동 이동한 현재 게시물과 삭제된 후보는 건너뛰고, 새로 수집한 게시물은 남은 목록에 추가합니다. 정지 후 같은 탭에서 재시작하면 남은 순서를 이어갑니다.
- **저장 목록 N개**는 수집한 고유 게시물 수입니다. 저장 실패 시 **임시 목록 N개**로 표시하고 현재 탭의 메모리 목록으로 계속 동작합니다. 임시 목록은 새로고침하면 사라질 수 있습니다.
- 전체 목록을 얻으려면 Instagram이 게시물을 끝까지 불러와야 합니다. 수집은 최대 10분이며, 목록 아래에서 8초간 변화가 없으면 중지합니다. 네트워크 지연과 실제 끝을 확실히 구분할 수 없어 전체 수집을 보장하지 않습니다. 수집한 목록은 유지되며 다시 수집해 누락 항목을 추가할 수 있습니다.
- 화면에 없는 랜덤 대상을 찾을 때는 프로필 맨 위부터 최대 2분간 탐색합니다. **탐색 중지**로 취소할 수 있습니다. 삭제·접근 제한·로딩 실패 등으로 찾지 못하면 자동 재생을 중지하고 안내합니다. 저장된 주소를 무조건 직접 열거나 Instagram 내부 API를 호출하지 않습니다.
- 모달 닫기 버튼과 프로필 목록의 실제 링크를 사용하므로 Instagram DOM 변경 시 수정이 필요합니다. 탐색 중에는 목록 스크롤이 보이며, 대상 게시물이 많을수록 이동이 느릴 수 있습니다.
- 확장 프로그램 저장소를 사용하기 위해 `storage` 권한을 추가했습니다. 기존 설치는 확장 프로그램을 새로고침한 뒤 Instagram 탭도 새로고침해 주세요.

### 자동 재생 상태 복원 (0.4.1)

게시물 목록 링크로 자동 이동하기 전에 대상 게시물과 재생 설정(랜덤/정방향, 사진 간격, 영상만, 남은 랜덤 순서)을 탭별 `chrome.storage.session`에 잠시 보관합니다. 페이지가 통째로 다시 로드되면 같은 대상에 한해 복원합니다. 복원 정보는 한 번만 사용하며 1분 후 만료됩니다. 일반적인 수동 새로고침이나 다른 게시물로 이동할 때 자동 재생을 새로 시작하지 않습니다.

복원할 게시물 모달은 최대 20초간 기다립니다. 지원하지 않는 독립 게시물 화면이면 복원하지 않고 안내합니다. 콘솔의 `[Insta Flow] 0.4.6 초기화`, 자동 정지 사유, 복원 메시지로 확장 프로그램 동작을 확인할 수 있습니다. 실제 Instagram 계정에서는 이 경로를 아직 검증하지 않았습니다.

### 좁은 화면의 미디어 배치 (0.4.2)

프로필 헤더·프로필 링크의 사진을 게시물 이미지 후보와 크기 계산에서 제외합니다. 전체화면에서는 미디어 바깥의 프로필·댓글 영역을 숨기고, 미디어를 브라우저 표시 영역의 가로·세로 중앙에 배치합니다. 원래 화면으로 전환하면 이 숨김과 중앙 배치를 해제합니다.

### 랜덤 순회 및 모달 닫기 (0.4.3)

랜덤 재생에서 매번 임의 대상을 다시 뽑는 대신 게시물 ID 목록을 섞어 차례로 순회합니다. 또한 닫기 버튼이 안쪽 dialog와 형제 위치에 있는 Instagram 화면에서도 찾도록 수정했습니다. 보이는 닫기 버튼이 여러 개라 모호한 경우에는 임의로 클릭하지 않고 정지 사유를 표시합니다.

### 좁은 화면의 도구 모음 (0.4.4)

도구 모음을 화면 아래쪽의 다음 게시물 버튼 위로 옮겨 상단 닫기·이전 게시물 버튼과 겹치지 않게 했습니다. 너비 600px 이하에서는 두 열로 배치하고, 높이가 부족하면 도구 모음 내부에서 세로 스크롤해 모든 항목에 접근할 수 있습니다.

### 버튼 모서리 유지 (0.4.5)

전체화면에서 왼쪽 모서리를 펴는 CSS의 대상을 미디어와 미디어 컨테이너로 제한합니다. `div`로 구현된 버튼과 버튼 내부 요소의 둥근 모서리는 유지합니다.

### 도구 모음 스타일 분리 (0.4.6)

Instagram의 기본 label 스타일이 사진 간격·영상만 글자를 검게 만들던 충돌을 수정했습니다. 글자색·여백·입력 크기·체크박스 크기를 명시하고, 좁은 화면에서는 같은 높이의 두 열로 조작부를 배치하며 저장 개수는 별도 줄에 표시합니다.

### 개발 검증

```sh
npm ci
npm run check
npm test
```

자동 검증은 모의 DOM과 저장소에서 목록 복원, 프로필 분리, 가상 스크롤, 수집 취소, 저장 실패, 여러 탭의 동시 저장 및 저장된 게시물을 찾아 모달로 재진입하는 흐름을 확인합니다. 0.4.0의 실제 Instagram 계정 검증은 아직 수행하지 않았습니다.
