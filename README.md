# Insta Flow

프로필에서 게시물을 열면 사진·영상을 원본 비율로 브라우저 표시 영역에 최대한 크게 표시하고 댓글 패널을 숨깁니다.

- 좌우 화살표 버튼 / ← →: 같은 게시물의 이전·다음 사진 또는 영상
- 첫 사진에서 ←: 이전 게시물의 마지막 사진으로 이동
- 마지막 사진에서 →: 다음 게시물의 첫 사진으로 이동
- 상하 화살표 버튼 / ↑ ↓: 이전·다음 게시물
- 최상단 반투명 **원래 화면 / 전체화면** 버튼: 기본 Instagram 레이아웃과 확대 화면 전환. 기본 화면에서는 확장 프로그램의 방향키 처리를 해제합니다.
- **자동 시작 / 자동 정지**: 지정한 간격으로 이동하며 기본값은 3초입니다. 간격은 1~3600초로 변경할 수 있습니다.
- **정방향**: 다음 사진 → 마지막 사진이면 다음 게시물의 첫 사진.
- **랜덤**: 현재 게시물의 사진·영상을 마지막 장까지 순서대로 표시한 뒤, 불러온 다른 게시물 중 하나를 무작위로 선택해 첫 장부터 재생합니다. 게시물 뷰어를 유지한 채 이동합니다. 후보를 찾을 수 없으면 정방향으로 이동합니다.
- 원래 화면으로 복귀하면 자동 이동을 중지합니다. 다른 브라우저 탭을 보는 동안에는 자동 이동을 건너뜁니다.
- 자동 이동 중 사진은 지정한 간격으로 넘기고, 영상은 `영상만` 선택 여부와 관계없이 실제 재생이 끝난 뒤 넘깁니다. 영상을 일시정지하면 기다립니다. 영상의 반복 재생은 자동 이동 중 잠시 해제하고 자동 정지 시 복원합니다.
- **영상만**: 사진을 건너뛰고 영상이 있는 슬라이드 또는 게시물을 찾습니다. 자동 이동과 수동 탐색에 적용됩니다. 영상 탐색은 최대 2분이며, 목록 끝에서 영상을 찾지 못하면 중지합니다.
- 게시물 목록 양 끝에서는 Instagram이 제공하는 이동 범위를 따릅니다.

## 설치

1. Chrome에서 `chrome://extensions`를 엽니다.
2. 개발자 모드를 켜고 **압축해제된 확장 프로그램을 로드합니다**를 누릅니다.
3. 이 저장소를 내려받은 폴더를 선택합니다.
4. Instagram 탭을 새로고침합니다.

기존 버전을 사용 중이면 확장 프로그램 관리 화면에서 **새로고침**한 뒤, Instagram 탭도 새로고침하고 프로필에서 게시물을 다시 엽니다.

Instagram의 현재 게시물 모달 DOM에 맞춘 초기 버전입니다. Instagram의 클래스나 구조가 변경되면 선택자를 수정해야 합니다. 독립 게시물 페이지·릴스 전용 화면은 별도 지원 대상입니다.

## 검증

실제 Instagram 프로필 게시물 모달에서 이미지 확대, 댓글 숨김, 사진/게시물 경계 이동, 좌우/상하 방향키, 원래 화면 토글, 3초 자동 이동, 랜덤 게시물 이동, 사진 건너뛰기 후 영상 도착을 확인했습니다. Dbo1uthEq2P 게시물의 7번째 가로 사진과 8번째 세로 사진 전환 및 호버 시 비율 유지도 확인했습니다.

0.2.3에서는 캐러셀 영역에 페인트 경계를 설정해 옆 사진이 가장자리에 비치지 않도록 하고, 반응형 이미지 후보 교체 중 같은 사진의 비율을 유지하며 표시 크기를 디바이스 픽셀에 맞춥니다. 확대 화면의 페이지 스크롤바도 고정합니다.

0.2.4에서는 전체/영상만 자동 재생 모두 영상 종료를 기다립니다. 1초 사진 간격을 초과해도 영상이 유지되고, 일시정지 중 이동하지 않으며, 실제 `ended` 이벤트 후 다음 게시물 첫 장으로 이동하는 것을 확인했습니다. 게시물 이동 버튼이 없는 영상 뷰어에서는 프로필 목록의 다음 게시물을 사용합니다.

## 추가 목록 로딩 조사

프로필 목록 끝으로 스크롤했을 때 게시물 링크가 12개 → 24개 → 36개로 늘어나는 것을 확인했습니다. 목록을 추가로 불러와 랜덤 후보를 확장할 수 있습니다. 현재 버전의 랜덤 후보는 이미 로드된 게시물이며, 자동 목록 추가 로딩은 아직 구현하지 않았습니다.
